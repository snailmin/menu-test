식단표 불러오기

첫 줄이 요일, 첫 칸이 구분(밥·국·주찬…)인 표여야 합니다.
요일이 세로로 되어 있으면 '행·열 바꾸기'를 누르세요.
한글(hwp)은 표를 드래그해 복사한 뒤 '붙여넣기로 불러오기'를 쓰면 됩니다.
파일은 외부로 전송되지 않고 이 브라우저 안에서만 처리됩니다.

붙여넣기로 불러오기

중복 기준

같은 주재료가 한 주에 N회 이상이면 중복으로 표시합니다.
같은 날·연속된 날 옵션을 켜면 더 엄격하게 검사합니다.
분류별 횟수 규칙은 '기준 설정' 탭에서 정합니다.

검수 결과

메뉴를 선택하면 오른쪽에서 재료 수정과 대체 메뉴 추천을 볼 수 있습니다.
같은 색은 같은 재료(분류)가 겹친다는 뜻입니다.
메뉴를 선택하면 중복 사유도 확인할 수 있습니다.

식단표를 불러오면 결과가 여기에 나타납니다.

분류별 주간 횟수 규칙

한 주 동안 해당 분류의 메뉴가 몇 번 나와야 하는지 정합니다.
비워 두면 제한하지 않습니다.
대체 메뉴 추천에도 이 규칙이 적용됩니다.

재료 분류 편집

재료별 분류를 선택해 바꾸세요. 새 분류를 만들려면 ‘새 분류 입력’을 선택한 뒤 이름을 적으세요.
분류를 비우면 분류하지 않고, 새 분류는 왼쪽 규칙 표에 자동으로 추가됩니다.

구글 스프레드시트 연결

시트는 읽기만 합니다. 게시한 시트는 링크를 아는 누구나 볼 수 있으니 개인정보는 넣지 마세요.

  1. 시트 탭 2개 만들기: 레시피 탭은 메뉴명·주재료·조리법·종류, 재료분류 탭은 재료·분류 열로 구성합니다.
  2. 웹에 게시: 파일 메뉴에서 공유한 뒤 웹에 게시를 선택합니다.
  3. CSV 링크 복사: 탭별로 CSV 형식을 선택해 게시하고 링크를 복사합니다.
  4. 연결: 아래 입력란에 두 링크를 붙여 넣고 시트에서 불러오기를 누릅니다.

레시피 DB 엑셀 등록

엑셀(.xlsx) 또는 UTF-8 CSV로 메뉴를 한꺼번에 등록합니다.
열 이름: 메뉴명, 주재료, 조리법, 종류(주찬/부찬/국)
재료가 여러 개면 / 또는 쉼표로 구분합니다.
'양식 내려받기'로 예시 파일을 받을 수 있습니다.
