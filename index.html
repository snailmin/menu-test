식단표 중복 검수

주재료가 겹치는 메뉴를 찾아 표시하고, 대체 메뉴를 추천합니다. 파일은 외부로 전송되지 않고 이 브라우저 안에서만 처리됩니다.

1. 식단표 불러오기

표 형태: 첫 줄이 요일, 첫 칸이 구분(밥·국·주찬…)이어야 합니다. 요일이 세로로 되어 있으면 '행·열 바꾸기'를 누르세요.
한글(hwp)에서는 표를 드래그해 복사한 뒤 아래 칸에 붙여넣으면 됩니다.

2. 중복 기준

분류별 주간 횟수 규칙

한 주 동안 해당 분류의 메뉴가 몇 번 나와야 하는지 정합니다. 비워 두면 제한하지 않습니다. 대체 메뉴 추천에도 이 규칙이 적용됩니다.

재료 분류 편집

재료가 어느 분류(생선류, 육류 등)에 속하는지 정합니다. 새 분류 이름을 입력하면 위 규칙 표에 자동으로 추가되고, 비우면 분류하지 않습니다.

3. 검수 결과

식단표를 불러오면 결과가 여기에 나타납니다.

구글 스프레드시트 연결

시트의 각 탭을 '웹에 게시'한 CSV 링크를 붙여넣으면 레시피와 재료 분류를 불러옵니다. 앱은 시트를 읽기만 하며, 시트를 고친 뒤에는 '시트에서 불러오기'를 누르세요. 링크는 이 브라우저에 저장되어 앱을 열 때 자동으로 불러옵니다.

레시피 DB

엑셀(.xlsx) 또는 UTF-8 CSV로 메뉴를 한꺼번에 등록합니다. 열 이름은 메뉴명, 주재료, 조리법, 종류(주찬/부찬/국)이고, 재료가 여러 개면 / 또는 쉼표로 구분합니다. 등록된 메뉴: 0개

백업 (레시피 DB · 규칙 · 메뉴 사전)

직접 입력한 재료 정보는 이 브라우저에 저장됩니다. 브라우저 데이터를 지우기 전에 내보내기로 백업하세요.
